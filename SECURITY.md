# Security

Use environment variables or ignored local configuration for credentials.
Never commit tokens, private keys, voice samples, personal rosters, databases,
deployment inventories, logs, generated scenes or account-specific voice IDs.
Use synthetic data for demonstrations. Do not connect a public demo to a private database.

If a credential was committed, rotate it and remove it from all affected history.
Report issues privately through the repository owner's GitHub contact options;
do not paste credentials or personal data into public issues.
